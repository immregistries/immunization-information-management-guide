# Topic template

Use this structure for new topic pages.

## Title

State the topic plainly and narrowly enough that the page can answer a coherent functional question.

## Draft status

Indicate whether the page is a draft, under review, or editorially approved for publication.

## Functional question

Describe the specific question the topic page is answering.

## Actors and workflow

Describe the participating actors and the workflow being discussed.

## Source facts versus derived information

Use direct labels in Markdown so readers can tell what kind of statement they are reading:

- **Existing requirement:** ...
- **Observed practice:** ...
- **Interpretation:** ...
- **Proposal:** ...
- **Unresolved:** ...

Repeat those labels throughout the page as needed.

## Observed practice

Summarize documented practice without implying universal consistency.

## Jurisdictional variation

Identify where policies, authority, workflows, or technical implementations differ across jurisdictions or programs.

## HL7 v2 realization

Describe the HL7 v2 representation only when supported by cited sources.

## FHIR realization

Describe the FHIR representation only when supported by cited sources.

## Sources

List the sources used for the page, with enough detail for readers to find the exact supporting material.

## Synthesis

Summarize the editorial understanding that emerges from the cited material and documented variation.

## Open questions

List ambiguities, evidence gaps, pending decisions, or questions for further research.
