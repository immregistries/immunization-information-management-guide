# Immunization Information Management Guide

Welcome to the draft publishing foundation for the **Immunization Information Management Guide**.

This site is being set up as an independent, evolving, evidence-based guide to how immunization information systems and their partners manage information.

At this stage, the site provides only the publishing foundation:

- a simple documentation structure
- navigation and search
- a reusable topic template
- contributor guidance
- an initial draft topic placeholder

This site does **not** yet attempt to make substantive claims about IIS behavior.

## Current status

- The guide is in an early editorial setup phase.
- Draft pages may define structure, scope, and documentation methods before topic content is developed.
- Future topic pages are expected to distinguish between source-supported facts, observed practice, interpretation, proposals, and unresolved questions.

## Important positioning

This guide is not currently an HL7 publication and is not presented as a replacement for AIRA's IIS Functional Guide series.

It is also not presented as endorsed by AIRA, CDC, ISO, or HL7.
