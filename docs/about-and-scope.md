# About and scope

The **Immunization Information Management Guide** is intended to document how immunization information systems and their partners manage information in practice and in specification.

## Purpose

The guide is intended to:

- synthesize established practice with citations
- describe a common functional model while identifying jurisdictional variation
- separate source-backed statements from editorial synthesis
- create a path for eventually relating the functional model to both HL7 v2 and FHIR

## What this guide is not

At present, this guide is not:

- an HL7 publication
- a replacement for AIRA's IIS Functional Guide series
- a source of uncited substantive claims about IIS behavior
- a statement of endorsement from AIRA, CDC, ISO, or HL7

## Scope boundaries for the initial site

For the initial publishing foundation, the site is limited to:

- project scope and editorial method
- contributor instructions
- a reusable topic structure
- placeholder topic content only

Substantive topic pages should be added only with supporting sources and clear labeling of claim types.
